# 🐟 AquaFarm Pro - نظام إدارة مزارع الأسماك

<div dir="rtl">

## 📋 نظرة عامة

**AquaFarm Pro** هو نظام متكامل لإدارة مزارع الأسماك، مصمم خصيصاً للسوق السعودي مع دعم كامل للمعايير المحاسبية السعودية (SOCPA) ومعايير HACCP للجودة الغذائية.

---

## ✨ المميزات الرئيسية

### 🎯 الإدارة التشغيلية

- **إدارة الأحواض**: متابعة شاملة لدورات الإنتاج والأحواض
- **مراقبة جودة المياه**: تسجيل وتحليل معايير جودة المياه
- **إدارة التغذية**: جدولة وتتبع عمليات التغذية
- **الصحة البيطرية**: تسجيل الفحوصات والعلاجات

### 📊 الإدارة المالية

- **المبيعات والمشتريات**: نظام متكامل لإدارة الطلبات والفواتير
- **المخزون**: إدارة ذكية للمخزون مع تقييم FIFO/LIFO
- **التكاليف**: تحليل تفصيلي للتكاليف حسب الأحواض ودورات الإنتاج
- **التقارير المالية**: تقارير متوافقة مع المعايير السعودية

### 👥 الموارد البشرية

- **إدارة الموظفين**: سجلات كاملة للموظفين
- **الحضور والانصراف**: نظام متكامل لتتبع الحضور
- **الرواتب**: معالجة الرواتب مع الاستقطاعات والبدلات
- **الإجازات**: إدارة طلبات الإجازات والموافقات

### 🔐 الأمان والجودة

- **نظام صلاحيات متقدم**: تحكم دقيق في الوصول حسب الأدوار
- **HACCP**: تسجيل ومتابعة نقاط المراقبة الحرجة
- **الشهادات**: إدارة شهادات الجودة والمطابقة
- **التدقيق**: سجل كامل لجميع العمليات

## 🚀 البدء السريع

### 1. استنساخ المشروع

```bash
git clone [repository-url]
cd FishFarmManagement
```

### 2. استعادة الحزم

```bash
dotnet restore
```

### 3. تحديث قاعدة البيانات

```bash
dotnet ef database update
```

### 4. تشغيل التطبيق

```bash
dotnet run
```

أو استخدم السكربت السريع:

```powershell
.\Scripts\quick-rebuild.ps1
```

### 5. إعداد أول تشغيل

في وضع الإنتاج، لا يتم إنشاء كلمة مرور افتراضية. إذا لم توجد حسابات مستخدمين، سيطلب التطبيق إنشاء حساب مدير النظام عند أول تشغيل.

في وضع العرض فقط، يمكن تفعيل بيانات Demo من `AppSettings:SeedDemoData`.
