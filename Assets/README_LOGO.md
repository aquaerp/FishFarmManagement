## 🎨 مواصفات الشعار

- **الأزرق العميق:** #003366

### العناصر المطلوبة

2. **النص:** "AquaFarm Pro"
3. **الخط:** Cairo Bold

## 📝 كيفية إضافة الشعار

### 1. تصميم الشعار

قم بتصميم الشعار باستخدام:

- Adobe Illustrator
- Figma
- Canva
- أو أي أداة تصميم

### 2. تصدير الملفات

احفظ بالصيغ التالية:

- **PNG** (شفاف) - للاستخدام في التطبيق
- **SVG** - للتعديل المستقبلي
- **ICO** - لأيقونة التطبيق

### 3. إضافة الملفات

ضع الملفات في `Assets/Images/`

### 4. تحديث الكود

الكود محدث تلقائياً في:

- `LoginForm.cs` - يبحث عن Logo_Full.png
- `MainForm.cs` - يستخدم AppIcon.ico
