# المرحلة الثانية — البناء والإصدار القابلان لإعادة الإنتاج

**التاريخ:** 11 أغسطس 2026  
**الحالة:** مكتملة محلياً؛ بانتظار إثبات خمسة تشغيلات CI متتالية

## ما تم تنفيذه

- تفعيل البناء الحتمي و`PathMap` وportable PDB على مستوى الحل.
- إضافة `packages.lock.json` للتطبيق والاختبارات وفرض locked mode في CI.
- تثبيت runtime المدعوم `win-x64` وقفل تبعياته.
- إنشاء `Scripts/New-ReleasePackage.ps1` لإنتاج حزمة self-contained مرقمة.
- إنشاء manifest يحتوي commit وSDK وقائمة الملفات وأحجامها وSHA-256 لكل ملف.
- إنشاء ZIP بترتيب ملفات وطوابع زمنية ثابتة وإصدار ملف SHA-256 مستقل.
- منع إنشاء حزمة Release من شجرة Git غير نظيفة.
- إنشاء `Scripts/Verify-ReproducibleRelease.ps1` لبناء حزمتين ومقارنة SHA-256.
- تحديث CI لرفض الإصدار غير القابل لإعادة الإنتاج ورفع ZIP وmanifest وchecksum كأدلة.
- تحديث فحص سياسة Release ليدعم مسار output الخاص بالـRID.
