### 3. إصلاح مشكلة النص المقلوب

#### المشكلة:
- استخدام `XStringFormats` خاطئ في PdfSharpCore
- عدم دعم RTL للنص العربي

#### الحل:
```csharp
// قبل الإصلاح (خاطئ)
XStringFormats.CenterCenter  // ❌ غير موجود
XStringFormats.CenterRight  // ❌ غير موجود

// بعد الإصلاح (صحيح)
XStringFormats.Center       // ✅ صحيح
XStringFormats.Right        // ✅ صحيح
XStringFormats.Left         // ✅ صحيح

// دالة RTL مخصصة
private void DrawRTLText(XGraphics gfx, string text, XFont font, ...)
{
    var rect = new XRect(x, y, width, 20);
    gfx.DrawString(text, font, XBrushes.Black, rect, format);
}
```
