## مخاطر P0 المثبتة

1. لا يوجد محرك فعلي لتطبيق `CurrentCulture` و`CurrentUICulture` عند تغيير اللغة.
2. النموذج الأساسي ومدير الثيم يفرضان RTL، لذلك الإنجليزية لا تتحول إلى LTR.
3. اللغة المحفوظة سابقاً تسمية عرض («العربية»/«English») وليست رمز ثقافة ثابتاً.
4. الرسائل والنصوص موزعة كسلاسل ثابتة، ولا توجد موارد ترجمة مركزية.
5. التاريخ والعملة منسقان بعدة صيغ محلية ثابتة، وبعض قيم الإعدادات محفوظة دون استهلاك مركزي.
6. عرض `ex.Message` قد يسرب رسالة إنجليزية أو تقنية إلى واجهة عربية.
7. بعض القيم المعروضة تستعمل `Enum.ToString()` فتظهر بالإنجليزية داخل الواجهة العربية.

## آلية القياس

تقوم أداة الجرد بمسح ملفات المصدر فقط، مع استبعاد `bin` و`obj` و`Migrations`، وتنتج JSON يمكن مقارنته في CI. يلزم فحص يدوي لاحق لتصنيف النتائج إلى نص واجهة، سجل تشخيصي، قيمة بروتوكول، أو بيانات أعمال.
