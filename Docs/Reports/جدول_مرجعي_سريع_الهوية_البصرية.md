## 📋 أمثلة الاستخدام السريع

### إنشاء زر

```csharp
// ❌ الطريقة القديمة
var button = new Button
{
    Text = "حفظ",
    BackColor = Color.FromArgb(46, 204, 113),
    ForeColor = Color.White,
    Font = new Font("Segoe UI", 10, FontStyle.Bold)
};

// ✅ الطريقة الصحيحة
var button = ThemeManager.CreateSuccessButton("حفظ");
```

### تلوين DataGridView

```csharp
// ❌ الطريقة القديمة
dataGridView.BackgroundColor = Color.White;
dataGridView.ColumnHeadersDefaultCellStyle.BackColor = Color.FromArgb(0, 122, 204);
dataGridView.DefaultCellStyle.SelectionBackColor = Color.FromArgb(52, 152, 219);

// ✅ الطريقة الصحيحة
ThemeManager.ApplyTheme(this); // يطبق على كل DataGridView تلقائياً
```

### إنشاء بطاقة معلومات

```csharp
// ✅ الطريقة الصحيحة
var card = ThemeManager.CreateInfoCard(
    title: "إجمالي المبيعات",
    value: "125,000 ريال",
    subtitle: "هذا الشهر",
    accentColor: ThemeManager.SuccessGreen,
    x: 20, y: 80, width: 250, height: 130
);
this.Controls.Add(card);
```

### عرض رسائل

```csharp
// ❌ الطريقة القديمة
MessageBox.Show("تم الحفظ بنجاح", "نجح", MessageBoxButtons.OK, MessageBoxIcon.Information);

// ✅ الطريقة الصحيحة
ThemeManager.ShowSuccess("تم الحفظ بنجاح");
ThemeManager.ShowError("حدث خطأ أثناء الحفظ");
ThemeManager.ShowWarning("البيانات غير مكتملة");
bool confirmed = ThemeManager.Confirm("هل تريد حذف هذا السجل؟");
```

    private void SetupUI()
    {
        // شريط العنوان

        // المحتوى

        this.Controls.Add(buttonBar);
    }
}
