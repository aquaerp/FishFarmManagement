**6 أنواع تقارير**:

**1. كشف الرواتب الشهري**:

- رقم الموظف، الاسم، القسم

- الخصومات، التأمينات
- صافي الراتب
- تاريخ الصرف
- فلترة: حسب الموظف، الفترة الزمنية

**2. تقرير الحضور اليومي**:

- قائمة حضور يوم محدد
- وقت الحضور، وقت الانصراف
- ساعات العمل الفعلية
- الحالة (حاضر/غائب/متأخر/إجازة/عطلة)
- دقائق التأخير
- دقائق الانصراف المبكر
- ساعات العمل الإضافي
- ملاحظات

**3. تقرير الحضور الشهري**:

- ملخص شهري لكل موظف
- أيام الحضور، أيام التأخير
- أيام الغياب، أيام الإجازة
- إجمالي التأخير بالدقائق
- إجمالي الإضافي بالساعات
- معدل الحضور %

**4. أرصدة الإجازات**:

- لجميع الموظفين النشطين
- إجازة سنوية: متاحة/مستخدمة/متبقية
- إجازة مرضية: متاحة/مستخدمة/متبقية
- حسب السنة الحالية

**5. دليل الموظفين**:

- معلومات كاملة عن الموظفين
- رقم الموظف، رقم الهوية
- القسم، المنصب، الحالة
- تاريخ التعيين
- الراتب الأساسي
- رقم الهاتف، البريد الإلكتروني، العنوان

**6. ملخص الأداء**:

- معدل الحضور %
- متوسط ساعات العمل اليومية
- إجمالي العمل الإضافي
- إجمالي التأخير بالدقائق
- إجمالي أيام الإجازات
- **التقييم التلقائي**:
  - ممتاز (≥95%)
  - جيد جداً (85-94%)
  - جيد (75-84%)
  - مقبول (65-74%)
  - ضعيف (<65%)
