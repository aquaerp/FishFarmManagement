## 🎯 الإضافات المطلوبة

### المرحلة 1 (شهر واحد - حرج)

```text
✅ نظام العملاء والمبيعات
   - Customer Model
   - SalesOrder Model
   - Invoice System (متوافق مع ZATCA)
   - الفوترة الإلكترونية + QR Code
   - تقارير المبيعات

✅ نظام ضريبة القيمة المضافة (15%)
   - TaxInvoice Model
   - VATReturn Model
   - التكامل مع هيئة الزكاة (ZATCA)
   - تقارير VAT ربع سنوية

✅ نظام التكاليف الشاملة
   - 23 نوع تكلفة (حاليًا: نوع واحد فقط)
   - ربط مع الموردين
   - تقارير تكاليف مفصلة

✅ التقارير المالية الأساسية (SOCPA)
   - قائمة الدخل
   - الميزانية العمومية
   - تحليل الربحية
   - ROI
```

### المرحلة 2 (شهر واحد)

```text
✅ نظام المخزون (متوافق مع SOCPA)
   - جرد الأعلاف والأدوية
   - تقييم المخزون (FIFO/المتوسط المرجح)
   - حركات المخزون
   - حد إعادة الطلب

✅ نظام الموظفين والرواتب (قانون العمل)
   - سجلات الموظفين الكاملة
   - الرواتب الشهرية
   - التأمينات الاجتماعية (GOSI)
   - منصة منشآت (MUDAD)
   - السعودة (Nitaqat)

✅ نظام الموردين والمشتريات
   - إدارة الموردين
   - أوامر الشراء
   - المدفوعات
```

### المرحلة 3 (شهر واحد)

```text
✅ نظام الزكاة والضرائب
   - حساب الزكاة الشرعية (2.5%)
   - إقرار الزكاة السنوي
   - ضريبة الدخل (للشركات المختلطة)

✅ التقارير المتقدمة
   - التدفقات النقدية (SOCPA)
   - قائمة التغيرات في حقوق الملكية
   - نقطة التعادل
   - لوحة معلومات مالية

✅ التكامل مع الأنظمة الحكومية
   - هيئة الزكاة (ZATCA)
   - منصة منشآت (MUDAD)
   - منصة قوى (QIWA)

✅ التحسينات
   - نظام التتبع
   - الأصول الثابتة
```
