2. **إنهاء جميع عمليات dotnet:**

   ```powershell
   Remove-Item "obj" -Recurse -Force
   Remove-Item "bin" -Recurse -Force
   ```

4. **إعادة البناء:**

   ```powershell
   dotnet restore
   dotnet build
   ```
