## 📋 سيناريوهات الاختبار

### 🔷 السيناريو 1: إنشاء فاتورة مبيعات جديدة (الإعداد)

#### الخطوة 1: افتح "أوامر المبيعات"
```
القائمة: المبيعات → أوامر المبيعات
```

#### الخطوة 2: إنشاء فاتورة مبيعات اختبارية
```
1. اضغط [جديد] أو [إضافة]

2. املأ البيانات:
   ┌─────────────────────────────┐
   │ رقم الطلب: SO-TEST-001     │
   │ تاريخ الطلب: [اليوم]       │
   │ العميل: [اختر أي عميل]    │
   │ الحالة: ⚠️ مهم جداً        │
   │          "Completed"        │
   │          (مكتمل)            │
   └─────────────────────────────┘

3. أضف بنود:
   ┌────────────────────────────────────┐
   │ المنتج: سمك بلطي              │
   │ الكمية: 100 كجم               │
   │ السعر: 50 ريال                │
   │ الدرجة: A                     │
   │ الخصم: 0                      │
   └────────────────────────────────────┘

4. احفظ الفاتورة
   ✓ تأكد من الحفظ بنجاح
   ✓ تأكد من الحالة = "مكتمل"
```

**النتيجة المتوقعة**:
```
✓ فاتورة مبيعات SO-TEST-001 محفوظة
✓ الحالة = Completed (مكتمل)
✓ المجموع الكلي = 5,750 ريال (تقريباً مع الضريبة)
```

### 🔷 السيناريو 3: التحقق من قاعدة البيانات

#### استعلام SQL للتحقق
```sql
-- فتح قاعدة البيانات
-- fishfarm.db

-- التحقق من الربط
SELECT 
    ti.InvoiceNumber AS 'رقم الفاتورة الضريبية',
    so.OrderNumber AS 'رقم فاتورة المبيعات',
    ti.TotalWithVAT AS 'المبلغ الإجمالي',
    ti.CreatedBy AS 'أنشئ بواسطة'
FROM TaxInvoices ti
LEFT JOIN SalesOrders so ON ti.SalesOrderId = so.Id
WHERE so.OrderNumber = 'SO-TEST-001';
```

**النتيجة المتوقعة**:
```
┌─────────────┬──────────────┬───────────┬──────────┐
│ الفاتورة    │ المبيعات     │ المبلغ    │ المستخدم │
├─────────────┼──────────────┼───────────┼──────────┤
│ INV-...     │ SO-TEST-001  │ 5750.00   │ admin    │
└─────────────┴──────────────┴───────────┴──────────┘

✓ SalesOrderId ليس NULL
✓ الربط صحيح
```

```

☑️ 7. الفاتورة تختفي من القائمة بعد التحويل
☑️ 8. لا يمكن تحويل نفس الفاتورة مرتين
```

## ❌ مشاكل محتملة وحلولها

### المشكلة 1: فاتورة المبيعات لا تظهر
```
الأسباب المحتملة:
  1. الحالة ليست "Completed"
     ↳ الحل: غيّر الحالة إلى "مكتمل"
  
  2. تم تحويلها سابقاً
     ↳ الحل: أنشئ فاتورة جديدة
  
  3. لا توجد فواتير أصلاً
     ↳ الحل: أنشئ فاتورة مبيعات أولاً
```

### المشكلة 2: خطأ عند التحميل
```
الأسباب:
  • لم تختر فاتورة
    ↳ الحل: اختر فاتورة من القائمة أولاً
```

### المشكلة 3: خطأ عند الحفظ
```
الأسباب:
  • لا يوجد عميل
  • لا توجد بنود
    ↳ الحل: تأكد من تحميل البيانات أولاً
```
