# سياسة الثقافات والتنسيق

## الثقافات المدعومة

- العربية: `ar-SA`، اتجاه RTL، اللغة الافتراضية الحالية.
- الإنجليزية: `en-GB`، اتجاه LTR.
- أي قيمة قديمة أو غير مدعومة تطبع إلى `ar-SA` لضمان سلوك متوقع.

## القرارات

- التاريخ التجاري والقانوني: ميلادي، وعرض قصير `dd/MM/yyyy` في اللغتين.
- التاريخ والوقت: `dd/MM/yyyy HH:mm`، مع استخدام المنطقة الزمنية المحلية للعرض فقط.
- التخزين: قيم `DateTime`/`DateOnly` أو ISO-8601؛ يمنع تخزين التاريخ كنص معروض.
- العملة الافتراضية: SAR؛ تعرض «ر.س» بالعربية و`SAR` بالإنجليزية.
- القيم النقدية: منزلتان عشريتان افتراضياً، ويحدد `CultureInfo` فواصل الآلاف والعشرية.
- ZATCA والتوقيع وواجهات التكامل: تستخدم التنسيق المحدد بالبروتوكول أو `InvariantCulture`، ولا تتبع ثقافة الواجهة.
- التقويم الهجري: خيار عرض منفصل مستقبلاً؛ لا يستخدم تلقائياً في القيود أو الفواتير حتى لا تتغير الدلالة المحاسبية.
