# مصفوفة التحقق التشغيلي لـ ZATCA — G4

**التاريخ:** 16 يوليو 2026  
**الحالة:** التحقق المحلي منجز؛ اعتماد SDK والبوابة الرسمية مع CSID حقيقي معلق.

## الأساس الرسمي

- [مواصفات الفاتورة الإلكترونية](https://zatca.gov.sa/en/e-invoicing/systemsdevelopers/pages/e-invoice-specifications.aspx): معيار XML وبيانات الأعمال المنشور من ZATCA.
- [متطلبات خصائص الأمان](https://zatca.gov.sa/en/e-invoicing/systemsdevelopers/pages/security-requirements.aspx): التوقيع والختم وخصائص الحماية.
- [حزمة SDK الرسمية](https://zatca.gov.sa/en/E-Invoicing/SystemsDevelopers/ComplianceEnablementToolbox/Pages/DownloadSDK.aspx): المرجع الإلزامي للتحقق النهائي؛ اجتياز SDK لا يعني قبول المستند من الهيئة.
- [دليل بوابة المطور](https://www.zatca.gov.sa/en/E-Invoicing/SystemsDevelopers/ComplianceEnablementToolbox/Documents/Developer%20Portal%20User%20Manual.pdf): onboarding وCompliance CSID وProduction CSID والتجديد ومسارا Reporting وClearance.

## مصفوفة التنفيذ المحلي

| المجال | الحالات | النتيجة |
|---|---|---|
| الأنواع الإيجابية | قياسية/مبسطة × فاتورة/دائن/مدين | 6/6 ناجحة؛ الجذر والكود والنمط والمسار صحيحة |
| الحالات السلبية | PIH ليس SHA-256، VAT غير صالح، عملة غير SAR، ضريبة غير 15%، خصم يتجاوز الإجمالي، إشعار بلا أصل/سبب | مرفوضة قبل إنشاء مستند قابل للإرسال |
| تسلسل ICV | توليد 1 إلى 10,000 وفحص التفرد والترتيب وحدود السالب و`long.MaxValue` | ناجح بلا تكرار أو التفاف عددي |
| انقطاع الشبكة | `HttpRequestException` | فشل مؤقت قابل للمحاولة ولا يلوث سجل منع التكرار |
| التكرار المتزامن | 100 طلب متطابق في الوقت نفسه | اتصال واحد فقط بالجهة وكل المستدعين يحصلون على النتيجة |
| صلاحية CSID | منتهي أو لم يبدأ سريانه | حجب قبل إنشاء أي اتصال شبكي |
| تعطيل الإنتاج | `Enabled=false` وبيئة `Disabled` | الاتصال محجوب افتراضياً |

## المتبقي للاعتماد الخارجي

لا تسجل G4 كـ`Passed` بناءً على الاختبارات المحلية وحدها. يلزم:

1. قبول شروط ZATCA وتنزيل الإصدار الحالي من SDK من الحساب المخول.
2. تشغيل ملفات الأنواع الستة وملفات الرفض عبر SDK وتوثيق رقم إصدار SDK والنتائج الخام.
3. الحصول على Compliance CSID حقيقي من بوابة المحاكاة، ثم اختبار onboarding والتجديد والانتهاء.
4. إرسال عينات Clearance وReporting إلى بيئة المحاكاة وأرشفة الطلب والاستجابة دون أسرار.
5. توقيع مختص ZATCA والمحاسب الضريبي على المصفوفة قبل تفعيل الشبكة أو الانتقال إلى الإنتاج.

حتى اكتمال ما سبق يبقى `ZatcaApi.Enabled=false` ولا يوجد ادعاء قبول أو اعتماد من ZATCA.
