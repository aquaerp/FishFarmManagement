# 🐟 Fish Farm Manager - نظام إدارة مزارع الأسماك

## 📋 نظرة عامة

نظام شامل لإدارة مزارع الأسماك في المياه العذبة والمالحة، مبني باستخدام C# و .NET 8 و Entity Framework Core.

## 📊 الميزات الرئيسية

### 1. إدارة الأحواض

- أنواع مختلفة (Hatchery, Nursery, GrowOut)
- حالات متعددة (Active, Maintenance, Empty)
- تتبع السعة والمساحة والعمق

### 2. دورات الإنتاج

- دورة حياة كاملة (Planning → Active → Completed)
- تتبع الزريعة والحصاد
- حساب مؤشرات الأداء:

  - FCR (Feed Conversion Ratio)
  - ADG (Average Daily Growth)
  - Survival Rate

### 3. مراقبة جودة المياه

- **دعم المياه العذبة والمالحة**
- المعايير المراقبة:
  - درجة الحرارة
  - الأوكسجين المذاب (DO)
  - الحموضة (pH)
  - الأمونيا، النتريت، النترات
  - الملوحة (للمياه المالحة)
  - العكارة والقلوية

### 4. إدارة التغذية

- أنواع الأعلاف (Starter, Grower, Finisher)
- تتبع الكميات والأسعار
- حساب FCR

### 5. التقارير

#### تقارير تشغيلية ✅

- تقرير الإنتاج
- تقرير التغذية
- تقرير جودة المياه
- تقرير الوفيات
- تقرير الأداء
- تقرير العلاجات

#### تقارير مالية ⚠️ (محدودة)

- تقرير تكاليف الأعلاف
- تقرير التكاليف الأساسي

## 📈 مؤشرات الأداء (KPIs)

### المؤشرات المحسوبة

- **FCR:** معدل التحويل الغذائي
- **ADG:** معدل النمو اليومي
- **Survival Rate:** معدل البقاء على قيد الحياة
- **Stocking Density:** الكثافة التخزينية
- **Feed Cost:** تكلفة الأعلاف

### المؤشرات المخطط إضافتها

- تكلفة الإنتاج لكل كجم
- ROI (العائد على الاستثمار)
- هامش الربح
- نقطة التعادل

## 🚀 البدء السريع

### المتطلبات

- Windows 10/11
- .NET 8.0 Runtime
- 100 MB مساحة فارغة على القرص

### التثبيت

1. تحميل أحدث إصدار من Releases
2. تشغيل `FishFarmManager.exe`
3. النظام سيُنشئ قاعدة البيانات تلقائيًا

### التطوير

```powershell
# استنساخ المشروع
git clone [repository-url]

# الانتقال إلى المجلد
cd FishFarmManager

# بناء المشروع
dotnet build

# تشغيل المشروع
dotnet run
```

### إنشاء Migration جديدة

```powershell
# إضافة Migration
dotnet ef migrations add YourMigrationName

# تحديث قاعدة البيانات
dotnet ef database update
```
