# المرحلة 6 — PDPL والأمن والجاهزية المؤسسية

**بدء التنفيذ:** 16 يوليو 2026  
**الحالة:** In Progress  
**قرار البوابة G6:** غير مجتازة — لا يوجد ادعاء امتثال قانوني أو اعتماد من مسؤول خصوصية مستقل.

## المراجع الرسمية

- [نظام حماية البيانات الشخصية — سدايا](https://dgp.sdaia.gov.sa/wps/portal/pdp/knowledgecenter/details/PDPL): يقرر حقوق العلم والوصول والحصول على نسخة والتصحيح والإتلاف وفق الضوابط.
- [اللائحة التنفيذية — سدايا](https://dgp.sdaia.gov.sa/wps/portal/pdp/knowledgecenter/details/PDPL2): تنص على الاستجابة لطلبات الحقوق خلال 30 يوماً، مع تمديد منضبط عند توفر مبرر وإشعار مسبق.
- [دليل سياسة الخصوصية — سدايا](https://dgp.sdaia.gov.sa/wps/portal/pdp/knowledgecenter/details/ElaborationandDevelopingPrivacyPolicyGuideline/): يحدد عناصر سياسة الخصوصية، ومنها الغرض والأساس النظامي والاحتفاظ والإتلاف والحقوق ووسيلة التواصل.

## خط الأساس القائم

| المجال | الوضع المثبت | الفجوة |
|---|---|---|
| الصلاحيات | أدوار RBAC وسجل أحداث أمني | مراجعة ربع سنوية موثقة لم تُنفذ بعد |
| سجل الأحداث | `SecurityAuditEvents` موجود | يلزم تحديد الأحداث الحساسة وفترة الاحتفاظ وحمايتها من العبث |
| التشفير | توجد بصمات وتواقيع لبعض الأدلة | لا دليل تشفير قاعدة البيانات أو إدارة مفاتيح منفصلة |
| حقوق الأفراد | لا يوجد مسار طلب منظم | يلزم التحقق من الهوية، سجل حالة، مهلة، وقرار معلل |
| سجل المعالجة | غير موجود | يلزم غرض/أساس/فئات/جهات إفصاح/نقل/احتفاظ لكل نشاط |
| الحوادث | لا يوجد تمرين موثق | يلزم خطة استجابة وحفظ أدلة وتمرين مكتبي |

## أولويات التنفيذ

1. إنشاء سجل أنشطة معالجة البيانات وجرد الفئات والاحتفاظ والأساس النظامي.
2. إنشاء مسار طلبات صاحب البيانات مع التحقق من الهوية ومهلة 30 يوماً وسجل تدقيق.
3. إصدار سياسة خصوصية وإشعار جمع بيانات قابلين للاعتماد بعد مراجعة مسؤول الخصوصية.
4. ضبط الاحتفاظ والإتلاف، ثم مراجعة صلاحيات ربع سنوية.
5. بناء خطة الاستجابة للحوادث وتمرين مكتبي، ثم فحوص SAST والحزم والاختراق.

## شروط إغلاق G6

- لا توجد ثغرة حرجة أو عالية غير معالجة، وخطة زمنية للمتوسطة.
- تنفيذ طلب صاحب بيانات تجريبي خلال المدة الداخلية المعتمدة.
- تنفيذ تمرين استجابة للحوادث وحفظ أدلته.
- توقيع مسؤول الخصوصية أو مستشار مؤهل على مصفوفة PDPL؛ هذا التوقيع غير متوفر حالياً.
