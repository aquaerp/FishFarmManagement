## 📋 خطوات النشر (Deployment)

### 1. الإعداد الأولي

```bash
# 1. نسخ الملفات
Copy-Item -Path "bin/Release/net8.0-windows/*" -Destination "C:\AquaFarmPro\" -Recurse

# 2. قاعدة البيانات
Copy-Item -Path "fishfarm.db" -Destination "C:\AquaFarmPro\Data\"

# 3. الإعدادات
Copy-Item -Path "appsettings.json" -Destination "C:\AquaFarmPro\"

# 4. الشهادات (إن وجدت)
# Copy ZATCA certificates to secure location
```

### 2. المستخدم الافتراضي

```text
Username: admin
Password: Admin@123
Role: Admin

⚠️ تحذير: يجب تغيير كلمة المرور فوراً بعد أول تسجيل دخول!
```

### 3. التكوين الأولي

1. افتح البرنامج
2. سجل دخول بحساب admin
3. اذهب إلى: أدوات > الإعدادات
4. أدخل بيانات الشركة
5. أدخل الرقم الضريبي (TRN)
6. احفظ الإعدادات

### 4. ZATCA Configuration (اختياري)

1. اذهب إلى: الضرائب > التكامل مع ZATCA
2. أدخل API Endpoint
3. أدخل API Key
4. حمّل الشهادة الرقمية
5. اختبر الاتصال
6. احفظ
