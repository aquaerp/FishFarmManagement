## ما نُفذ

- توحيد مسار SQLite عبر `RuntimePaths` وإزالة الإنشاء النسبي الصامت لـ`fishfarm.db`.
- إضافة فحوص بدء التشغيل للمجلدات والصلاحيات والمساحة والإعدادات الإنتاجية.
- منع Demo في Production ومنع تضمين `DataSeeder` في Release.
- إلزام Demo في Debug بسر خارجي قوي عبر `AQUAFARM_DEMO_PASSWORD`.
- استبدال النسخ المباشر بـSQLite Online Backup.
- تشفير النسخ بـWindows DPAPI وكتابة SHA-256 checksum والتحقق من `PRAGMA integrity_check`.
- إضافة pre-restore backup وrollback تلقائي عند فشل الاستعادة.
- نجاح ثلاث استعادات متتالية في اختبار آلي.
- إضافة قفل حساب محفوظ في قاعدة البيانات وmigration، مع BCrypt وترقية SHA256 القديمة عند الدخول الصحيح.
- تشفير ZATCA API Key عند التخزين باستخدام DPAPI.
- إضافة معالج أخطاء مركزي يعرض رقم تتبع دون كشف تفاصيل الاستثناء للمستخدم.
- إضافة سجل تدقيق أمني وإداري منظم داخل قاعدة البيانات، مع correlation ID ومنع تخزين الأسرار.
- التحقق بعد الهجرة من عدم وجود migrations معلقة ونتيجة SQLite `integrity_check`.
- إصلاح عزل مخرجات CI لينتج `Phase0ArtifactsRoot` حزمة Release قابلة للفحص فعلياً.
- تفعيل النسخة الخارجية الإلزامية على قرص USB `E:` باسم `Abusajad` وفشل بدء التشغيل بأمان عند غيابه.
- تحديث حزم NuGet وإزالة جميع الثغرات المعروفة التي أبلغ عنها المصدر الرسمي.
- إضافة فحوص CI للثغرات والأسرار وسياسة حزمة Release.
