# المرحلة الأولى — خط الأساس وحوكمة المصدر

**التاريخ:** 11 أغسطس 2026  
**الحالة:** مكتملة  
**المرجع:** `COMMERCIAL_RELEASE_10_STAGE_PLAN_AR.md`

## نطاق الإصدار التجاري الأول

- تطبيق Windows مكتبي مبني على .NET 8 وWinForms.
- مزرعة واحدة وجهاز تشغيل واحد.
- قاعدة SQLite محلية محفوظة في مجلد بيانات المستخدم.
- لا يدعم الإصدار الأول مشاركة ملف القاعدة عبر الشبكة أو العمل المتزامن من عدة أجهزة أو إدارة عدة فروع.
- لا تعد المحاسبة أو الفوترة الإلكترونية معتمدة رسمياً حتى اجتياز بوابة المرحلة السادسة وتوقيع المختصين.
- تكامل ZATCA يبقى معطلاً في الإنتاج إلى حين اكتمال الاختبارات والاعتماد الرسمي.

## خط الأساس التقني

- SDK المعتمد: `.NET SDK 8.0.421`، مثبت بواسطة `global.json`.
- إطار التشغيل: `net8.0-windows`.
- مدير الحزم: NuGet مع المصدر الرسمي `nuget.org` وإلغاء fallback folders الموروثة من الجهاز.
- بوابة التحقق الأساسية: `Scripts/Verify-G0.ps1`.
- نظام قاعدة البيانات المعتمد للـPilot: SQLite فقط.

## سياسة المصدر والإصدار

- يمنع التطوير المباشر على `main` بعد تثبيت خط الأساس.
- كل تغيير يمر بفرع مستقل وPull Request ومراجعة واختبارات CI.
- لا ينشأ tag إصدار من شجرة عمل تحتوي ملفات معدلة أو غير متتبعة.
- لا تحفظ قواعد البيانات أو الأسرار أو السجلات أو مخرجات البناء في Git.
- كل إصدار تجاري يربط بـcommit ونتيجة CI وchecksum للحزمة وRelease Notes.

## حالة شجرة العمل عند بدء المرحلة

الشجرة الحالية تحتوي تعديلات كبيرة سابقة وملفات غير متتبعة. تم الحفاظ عليها ولم تدمج أو تحذف. قبل إغلاق المرحلة يجب على مالك المنتج مراجعتها وتقسيمها إلى commits مترابطة أو اعتمادها كدفعة baseline واحدة بعد نجاح الاختبارات.

## سجل القرارات المعمارية الأولي

### ADR-001 — تثبيت .NET 8

تم اعتماد SDK 8.0.421 لأنه يطابق Target Framework وبيئة CI الحالية، ويمنع اختلاف نتائج البناء الناتج عن اختيار SDK 10 تلقائياً.

### ADR-002 — SQLite للإصدار الأول

SQLite معتمدة فقط لنشر محلي على جهاز واحد. أي دعم لأجهزة أو فروع متعددة يتطلب قراراً معمارياً جديداً وقاعدة خادم ومراجعة للتزامن والأمن والترحيل.

### ADR-003 — عدم اعتماد ZATCA افتراضياً

يبقى التكامل معطلاً حتى وجود أدلة اختبار واعتماد رسمية. وجود الكود والاختبارات المحلية لا يساوي اعتماداً تنظيمياً.
