# المرحلة 0 — الحوكمة والنطاق والقرارات

**بدأت:** 12 يوليو 2026  
**الحالة:** مكتملة ومعتمدة ضمن قرار G0 بتاريخ 13 يوليو 2026

هذه الوثيقة هي المصدر المعتمد للمرحلة 0؛ تقارير الاكتمال التاريخية ليست دليل قبول من دون اختبار أو أثر مرتبط هنا.

## نطاق الإصدار التجاري الأول

الإصدار الأول يستهدف منشأة واحدة ولغة عربية على Windows 10/11 x64. يبدأ Pilot بمحطة واحدة. التشغيل الشبكي ينتظر اختبار التزامن وقرار قاعدة خادم. لا يشمل الإصدار الأول SaaS أو الجوال أو عدة كيانات قانونية.

### Must

- المستخدمون والأدوار وفصل الموافقات الحرجة.
- الأحواض ودورات الإنتاج والتغذية والنفوق وجودة المياه والصحة.
- العملاء والموردون والمبيعات والمشتريات والتحصيل والسداد.
- المخزون والاستلام والجرد والتكلفة والتتبع.
- دفتر أستاذ مزدوج القيد، فترات، إقفال وقوائم مالية.
- الأصول الثابتة والأصول البيولوجية وفق السياسة المعتمدة.
- VAT والفواتير والإشعارات وتكامل ZATCA ضمن نطاق العميل.
- النسخ والاستعادة والتدقيق والمراقبة والتثبيت والترقية والدعم.

### Should

- الموارد البشرية والحضور والرواتب الأساسية.
- HACCP والجودة وCAPA والاستدعاء.
- تصدير Excel/PDF ولوحات المؤشرات المعتمدة.

### خارج الإصدار الأول

- الويب والجوال وSaaS متعدد المستأجرين.
- الدمج البنكي والدفع الإلكتروني.
- عدة شركات وتوحيد القوائم والعملات المتعددة.
- ضرائب دول أخرى أو ادعاء شهادة ISO آلية.

بعد G0 لا يضاف Must إلا بطلب تغيير يوضح أثر الوقت والكلفة والمخاطر.

## ADR-001: قاعدة البيانات والنشر

**الحالة:** مقبول مرحلياً.

الكود يستخدم SQLite في `%APPDATA%` بينما وثائق تاريخية تشير إلى SQL Server. القرار:

1. يبقى SQLite للتطوير والاختبار وPilot أحادي المحطة فقط.
2. قبل التشغيل متعدد المستخدمين تجرى مقارنة PostgreSQL وSQL Server واختبار 20 مستخدماً متزامناً.
3. يمنع تسويق الإصدار الحالي كحل شبكي حتى قرار ADR لاحق.
4. يجب أن تنسخ خدمة النسخ قاعدة connection string الفعلية، لا ملفاً نسبياً ثابتاً.

معيار القرار النهائي: p95 أقل من ثانية، بلا أقفال أو فقد معاملات، ونجاح الهجرة والنسخ والاستعادة مع توثيق كلفة خمس سنوات.

## تعريف الإنجاز

لا تصبح المهمة `Done` إلا بعد:

- وجود متطلب ومعيار قبول ومالك.
- نجاح بناء Release والاختبارات.
- اختبارات إيجابية وسلبية وحدود للمنطق الحرج.
- غياب الأسرار وبيانات Demo والافتراضات الإنتاجية الصامتة.
- تحقق الصلاحيات والتدقيق ومعالجة الأخطاء.
- توثيق الهجرة والرجوع وتحديث الأدلة.
- مراجعة كود مستقلة للمهام المحاسبية والأمنية والضريبية.
- قبول مالك العملية والمختص المنطبق.

نسب المتابعة: 0%، 25%، 50%، 75%، 100% فقط.

## إيقاع المتابعة

- تحديث السجلات أسبوعياً.
- اجتماع مخاطر وعوائق 30 دقيقة أسبوعياً.
- قياس عدد المتطلبات المقبولة، لا عدد الملفات المعدلة.
- تصعيد أي عائق يتجاوز يومي عمل.
